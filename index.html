One-time setup

This app needs your Firebase project config. Open index.html and paste it into FIREBASE_CONFIG at the top of the script.

  1. Firebase Console → Project settings → Your apps → Web app
  2. Copy the firebaseConfig object
  3. Enable Realtime Database and Storage
  4. Apply the rules from README.md
